# Using srnp

A component in srnp does four things: it publishes pairs, reads them, subscribes
to other components' pairs, and runs callbacks when those change.

- **[Quickstart](quickstart.md)** — a master, a publisher and a subscriber, with
  the output you should see.
- **[Concepts](concepts.md)** — owners, pairs, subscriptions, callbacks and
  meta-pairs, and what the master does.
- **[Building](building.md)** — dependencies, cmake, install.
- **[Running](running.md)** — the master, the environment variables, logging.
- **[API reference](api-reference.md)** — every public function, grouped by task.
- **[Changelog](changelog.md)** — what changed between releases.

If you are changing srnp itself rather than using it, you want the
[developer section](../dev/index.md) instead.
